## 🩺 How I troubleshoot

1. **Scope the blast radius** — what's broken, for whom, since when.
2. **Walk the path layer by layer** — Route → Service → Endpoints → Pod → container → node — and prove each hop instead of guessing.
3. **Fix the cause, not the symptom** — then verify with the same check that showed the failure.
4. **Write it down** — root cause, fix and prevention, so the next person (or me) is faster.
